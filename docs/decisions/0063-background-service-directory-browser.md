# ADR 0063：本机后台服务与 owner 目录浏览

- Status: Accepted
- Date: 2026-10-15

## Context

公网工作台启动项目只能手动输入电脑路径；原生目录窗口出现在电脑桌面，不能替代手机上的目录浏览。前台启动器退出也会结束所属 CLI，不适合用户长期从远端连接。用户要求明确的后台开启、完整关闭、可选登录自启及首次电脑注册引导。

## Decision

1. macOS 使用用户级 LaunchAgent 管理 Application，默认手动 `start`，可选 `autostart on/off`；登录期间可常驻，终端和网页退出不结束服务。沿用有效配置/数据目录作用域、私有实例入口与 flock，不按裸 PID 接管或删除锁。其他操作系统服务管理、本轮菜单栏 UI 不在范围内。
2. `start` 不启动/恢复 CLI。首次交互启动没有电脑绑定或明确需要重新认证时，打印引导并打开本机 `/relay`；已有绑定保持原 enabled 意图，临时断网只重连。非交互启动和系统自启不弹浏览器、不等待注册。中转地址由用户选择，注册继续使用现有设备码登录/批准和私有凭据存储，不保存账号密码。
3. `stop` 通过仅 loopback、私有实例能力验证的控制接口停止受理新启动，回收全部所属 CLI/代理/连接并确认退出。卸载 LaunchAgent 后不立即重启；保留登录自启偏好。异常退出只限频重启 Application，不恢复 CLI 或重放输入。服务登记绑定当前可执行文件；升级/卸载在改文件前检查本安装所有作用域，活动或无法验证的登记阻止操作。卸载只移除已验证且不活动的所属登记，不自动停止服务。
4. 网页新增 owner 目录浏览器，访问连接电脑当前系统用户可读的目录；仅枚举当前层目录元信息，不读文件正文、不执行 Shell、不创建目录。新增 `POST /workbench/v1/application/directories`，加入中转精确白名单；Application owner 与有效 RemoteOwner 可用，PairedRun 不可用。
5. 路径规范化，符号链接显示实际目标；目录选择与启动准入独立。浏览只填回原表单并触发现有目标校验；受理和 spawn 前仍复核项目身份。Run 内固定根、敏感文件与路径逃逸规则不变。
6. 列表采用有界扫描和短期快照分页；超限明确 `truncated`，不宣称列表完整。能力字段 `directoryBrowserAvailable` 为可选兼容扩展，旧后端缺失时保留手动输入，不提升传输/API 版本或迁移数据库。

## Alternatives

- 仅使用 `nohup`：缺少稳定的服务归属、异常重启和登录自启管理。
- 远端触发原生目录窗口：用户仍需回到电脑桌面选择。
- 只开放固定项目根：不能满足用户浏览系统可访问路径的决定；完整 owner 已拥有原生 CLI，目录列表不构成新的 OS 沙箱。

## Consequences

工作台与中转仍独立构建，目录读取和 CLI 留在电脑。完整 owner 能看到电脑路径和目录名，必须保持现有账号归属、固定页面授权及撤销检查；中转仍为可信方，不是端到端加密。目录扫描不得反压 PTY/模型转发。launchd 不保证注销后、睡眠期间或关机时在线，真实登录自启及睡眠恢复须单独实测，不能由单元测试推导。
