README、使用指南、详细设计与历史首页契约已同步实际默认入口、命令、目录、生命周期与 Run API。私有入口是 `.codex-web/runtime/<scope>/instance.json`；运行接口必须显式使用 `/workbench/v1/runs/{runId}/…`，旧无 Run 前缀别名返回 404。ADR 0053 改为 Accepted 表示采用并实现架构决定，完整阶段状态仍只由实施计划维护。

支持范围仍限定 macOS 当前 `unmanaged-custom` / Responses / 静态 bearer。其他 provider、managed/ChatGPT、真实 provider WS、Linux/Windows 和更多手机真机体验未新增验收。通用合成 WS 回归不能替代真实 provider 接入。

非空 `history_base` 可读但不恢复；增加缓存预算不会自动补回未变化会话的省略正文。清理预览 `Stale` 曾单次出现，根因尚未确认，失败诊断保留；随后测试通过不能当作根因关闭。

用户整片试用路径：启动首页 → 搜索/阅读历史 → 选择项目开始新对话 → 明确继续可恢复会话 → 另项目新标签并行输入 → 返回首页 → 停止单个项目并退出应用。手机多 Run 真机体验仍需用户环境验证。

本轮不做配置/数据库迁移，不恢复旧控制内核，不新增自动输入或远程管理能力；不自动提交、推送或发布。交付后曾按用户要求暂停等待试用；2026-09-30 收到的用户确认见 §7。
