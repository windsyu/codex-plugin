# Codex View 前端改进依据

[前端设计](README.md) · [工作台方案](../workbench.md) · [本机交互](../../interactions/workbench.md) · [前端维护入口](../../architecture/workbench.md)

本次前端改进以用户提供的 `index.jpg` 和 Open Design 原稿为起点，补全已实现的远程能力后，由 Open Design 完成商业版布局。原图、原型导出和阶段任务书属于本地资料，由 Git 忽略；本文维护持续有效的设计契约。生产实现位于 `web/` 和 `relay/static/`。

当前实现将共享产品导航、项目与会话侧栏、连续阅读、会话内文件面板和原生终端接入既有组件与路由。本文说明实际映射和剩余边界；原型的演示内容不能替代运行证据。

## 1. 用户价值与范围

用户应能从项目定位到会话，连续阅读正文，需要时查看相关文件或修改，同时保留当前原生终端；阅读历史时明确知道终端属于哪次运行。成功标准是减少上下文切换，保持正文结构和阅读位置，并清楚表达需要处理的异常。

本次设计范围是工作台的布局、导航、消息阅读、辅助面板、视觉 token、响应式和可访问性，同时保留已实现的本机公网连接、门户电脑选择、远程工作台及局域网配对。中转访问同一工作台时继续使用现有固定授权上下文。

非目标包括新增网页聊天输入器或审批协议、模拟官方 CLI、编辑文件、Git 写入、改动模型代理和存储、自动恢复 CLI、扩大设备权限，以及重新实现中转账号流程。门户只同步视觉；添加项目、新建会话和终端输入继续使用真实能力，不采用原型演示接口。

## 2. 布局与交互

| 区域 | 商业版设计与生产表达 |
| --- | --- |
| 顶部与项目侧栏 | 顶部产品导航和目标电脑身份；左侧查找打开的项目、当前 Run、全部历史、启动、设置与连接入口；实际授权决定可见操作 |
| 会话头部 | 项目名称、Run 短 ID、阅读连接状态、终端开关和会话选项；下一行放对话/历史及文件/搜索/更改入口。分支来自 Git 读取结果，不填示例分支 |
| 中央连续阅读 | 原生用户提交、模型 Markdown、可折叠工具过程与有来源的拟议修改；正文独立滚动，状态依真实证据展示 |
| 辅助面板 | 文件、搜索和更改在阅读区下方展开，保留当前对话或历史；工具过程沿用工具卡与调用详情，不伪装成文件状态 |
| 原生终端 | 默认右侧并排，可切到底部、折叠和拖动大小；输入与确认留在 xterm 内 |
| 历史提示 | 切换历史仍使用同一阅读布局，提示终端属于当前运行会话，并提供返回入口 |
| 底部状态 | 阅读区提供“在终端继续”，底栏保留真实用量与保存状态，不展示示例快捷键或虚构完成状态 |
| 远程连接补全 | 本机公网管理、门户“我的电脑”、当前电脑/访问范围常驻标记、Run 局域网配对，以及断线和授权失效状态，见[远程连接设计](remote-access.md) |

原稿的消息渲染区分摘要、正文和代码/日志：列表摘要提取可读文字，模型正文解析 Markdown，代码和日志保留原文、缩进与换行。长回复的继续阅读在完整内容块边界处理；成功工具过程默认折叠，异常和输入不确定性就地呈现。

这些展示需要接入真实证据：截图中固定的“Codex”、时间、等待确认、文件数量和 Diff 都是示例；生产模型身份、响应状态、执行结果与覆盖信息继续遵守[详细设计](../workbench-detailed-design.md)。建议修改、工作区 Diff 和工具已执行结果必须分别标识。

## 3. 商业版视觉基准

以下数值根据 Open Design 商业版设计确定，维护入口是生产 [tokens.css](../../../web/src/workbench/tokens.css)和[门户样式](../../../relay/static/portal.css)。

| 类别 | 商业版值 |
| --- | --- |
| 页面与侧栏 | 页面 `#14161b`；侧栏/顶栏 `#191b21`；阅读 `#16181e` |
| 容器与悬停 | 普通表面 `#20232b`；悬停 `#292e38` |
| 终端容器 | 保留现有 `#0d0f10`；xterm 内部 ANSI 调色板及 OSC 契约独立 |
| 文字 | 正文 `#edf0f6`；次级 `#bec5d1`；辅助 `#9aa4b5` |
| 线框 | 常态 `#2c313c`；强调 `#424b5c` |
| 交互强调 | 链接/聚焦 `#a3bfff`；选中背景 `#26344f`；主操作蓝 `#3869e8` |
| 语义状态 | 绿 `#8bd3b0`；琥珀 `#edc78a`；红 `#ffa6b3`，同时显示文字或图标 |
| 字体 | 中文系统字体；代码与终端使用 SF Mono / Menlo / Consolas 回退 |
| 字号与行高 | 界面 12–14px；模型正文 16px / 1.8；标题 20–24px；辅助 10–12px |
| 空间与圆角 | 4px 基础节奏；控件 6px；面板 8–10px；180ms 状态反馈 |
| 生产默认宽度 | 侧栏 240px；右侧终端 400px、可调；正文最大约 800px |

界面以低饱和表面、细边框、对齐和留白分层，用户原生提交有背景，模型正文沿连续阅读流排布。键盘聚焦保留明确描边；减少动态效果偏好关闭动画与过渡。

### 响应式

| 生产断点 | 布局变化 |
| --- | --- |
| ≥1200px | 项目侧栏、连续阅读与右侧终端并排；可切为底部终端 |
| 768–1199px | 侧栏 220px；终端在底部，横向分隔线可调高度 |
| ≤767px | 项目导航移入模态抽屉；阅读/终端切换完整工作区，保留同一个 xterm |
| ≤479px | 文件树与文件阅读上下排列，辅助面板自身滚动 |

辅助面板隐藏或手机切到终端时暂停文件、目录和 Git 选择的轮询；跨回断点或阅读视图后恢复当前选择。代码在自身容器滚动。桌面浏览器的手机视口不代替真机和软键盘验收。

## 4. 生产落地映射与边界

| 设计方向 | 实现 | 保持的边界 |
| --- | --- | --- |
| 项目与会话统一导航 | [WorkbenchFrame.tsx](../../../web/src/workbench/WorkbenchFrame.tsx)提供共享导航、打开的项目、目标电脑/访问范围；[HistoryHome.tsx](../../../web/src/workbench/HistoryHome.tsx)保留首页、历史、启动与配置 | Application、Run 和历史 entry 身份分开；同一份 application 轮询供 Frame 和首页使用，实例变化报错而不接管新实例 |
| 会话内辅助面板 | [App.tsx](../../../web/src/workbench/App.tsx)保留 [routes.ts](../../../web/src/workbench/routes.ts)的 files/search/git 地址，在阅读下方打开真实面板 | 直达地址、浏览器返回和固定授权继续有效；关闭返回先前的对话/历史并恢复焦点，独立 Run 根入口中的工具文件链接也进入该 Run 的文件地址 |
| 实时和历史统一阅读 | 实时与 Run 保存历史已复用 [ModelMessage.tsx](../../../web/src/workbench/ModelMessage.tsx)、[ToolCard.tsx](../../../web/src/workbench/ToolCard.tsx)；跨来源历史由 [LibraryReader.tsx](../../../web/src/workbench/LibraryReader.tsx)和 [HistoryRecord.tsx](../../../web/src/workbench/HistoryRecord.tsx)展示 | 可统一呈现规则与组件，但保留来源、覆盖、截断、调用详情和历史模式差异 |
| 长回复完整阅读 | ModelMessage 对当前 item 文本调用安全 Markdown renderer；HistoryRecord 在解析前截取模型文本前 4000 字符，超限显示摘要提示，详情另读 | 原稿中的演示 Diff 只是示意；实施时需兼顾完整 Markdown 块、有界读取、分页和挂载预算，不能只删除截断保护 |
| 会话摘要与原文分离 | [presentation.rs](../../../src/history/library/presentation.rs)处理历史展示文本及 summary | 先用标题、链接、代码和换行样例确认摘要问题；正文、代码与日志不采用批量移除 Markdown 字符的办法 |
| 原生终端持续可用 | [TerminalPanel.tsx](../../../web/src/workbench/TerminalPanel.tsx)保持同 Run 挂载；[DockSeparator.tsx](../../../web/src/workbench/DockSeparator.tsx)提供指针/键盘尺寸调整和左右/底部布局 | [terminalClient.ts](../../../web/src/workbench/terminalClient.ts)的控制权、恢复与输入协议不变；显示偏好仅保存 dock 位置，不保存或重放输入 |
| 文件/搜索/Diff 阅读 | [WorkspacePanel.tsx](../../../web/src/workbench/WorkspacePanel.tsx)与 [FileReading.tsx](../../../web/src/workbench/FileReading.tsx)已有只读查询和阅读 | 移动容器时复用查询能力，保留项目作用域、来源时间、错误及当前选择 |
| 远程连接与设备接入 | [RelayPanel.tsx](../../../web/src/workbench/RelayPanel.tsx)、[AccessPanel.tsx](../../../web/src/workbench/AccessPanel.tsx)与[门户](../../../relay/static/portal.js)已实现公网绑定、电脑选择和 Run 配对 | 新布局保留这些入口与状态；本机 owner、RemoteOwner、PairedRun 的操作范围分别呈现，不将原稿遗漏当作删除功能的依据 |
| 主题统一 | [tokens.css](../../../web/src/workbench/tokens.css)、[frame.css](../../../web/src/workbench/frame.css)、[session.css](../../../web/src/workbench/session.css)与[门户](../../../relay/static/portal.css)采用商业版石墨灰方案 | 门户同步电脑行、表单和状态视觉，账号/授权 DOM 与协议不变；终端配色独立 |

模型正文使用原安全 Markdown renderer；历史摘要、挂载预算、来源、缺口和按需详情保持现有约束。本轮没有实现原型中不存在的真实分支摘要、文件修改确认或网页审批。

## 5. 接入生产时必须保持的约束

- 原生 CLI 是唯一对话输入、信任、审批和 Slash 入口。原稿的示例回复、按键解释、审批分支与模拟文件修改均不进入生产。
- 阅读历史、切辅助面板、折叠或移动终端不启动/停止 CLI，不重放输入，不将历史正文写入当前原生会话。
- 当前响应已结束、工具参数已生成、工具执行成功、整轮完成及 CLI 退出分别表达，不能从截图中的状态标签互相推导。
- 权限按 Application/Run、来源和 capability 校验；导航变化继续保留中转固定授权、配对设备的作用域和失效清屏。
- Markdown、ANSI、路径、代码和日志都是不可信输入。正文复用安全 renderer；跨来源历史继续阻止嵌入媒体自动请求。
- 长内容保持有界查询、按需详情与挂载窗口；完整阅读不等于一次渲染整个 store，也不能隐藏缺口或未保存尾部。
- 界面观察和交互不能增加模型/PTY 转发对网页、磁盘或 ACK 的依赖。

## 6. 验证与后续边界

1. 单元回归覆盖共享轮询、实例不匹配、电脑 metadata 安全链接、身份入口、抽屉、Run 路由、文件/历史保留、终端折叠和手机隐藏选择停止轮询。
2. `node web/e2e/product-design-probe.mjs` 在隔离系统 Chrome 中运行真实生产组件及合成 API/SSE/WS，检查五种宽度、连续阅读、辅助面板、同一 xterm/连接、角色与门户状态。
3. 标准 `node scripts/dev.mjs check` 运行文档、类型、测试和双组件构建；浏览器 `e2e` 使用系统 Chrome。执行结果与截图保存在受管产物，不能用原型截图冒充生产界面。

本轮不改变 API、数据库、身份或加密协议。真实 CLI/PTY 输入编辑、手机键盘和真实网络依旧需要各自运行环境；合成视觉专项不证明这些行为。跨来源历史模型摘要仍有 4000 字符预览上限，完整详情按需读取，没有把原型的长文演示当作该限制已经解除。

### 验收场景

| 场景 | 应观察的结果 |
| --- | --- |
| 从实时切到历史并返回 | 消息结构一致，来源明确，阅读位置恢复；当前终端内容和输入草稿保留 |
| 长 Markdown 与代码日志 | 实时正文使用安全 Markdown；历史摘要注明预览上限并可读取详情；代码符号、缩进与换行保留 |
| 展开工具与异常记录 | 成功过程可折叠，异常/缺口/结果未确认可见，调用详情仍可访问 |
| 打开文件/搜索/更改 | 对话保持可阅读，终端保持挂载；关闭面板恢复位置与触发控件焦点 |
| 打开既有功能页直达链接 | 指向相同 Run/项目与功能，中转授权保持绑定，返回历史行为可预期 |
| 拖动、折叠和切换终端位置 | xterm 正确 resize，未重建 CLI、未补发输入，键盘可操作分隔线 |
| 1440 / 1024 / 736 / 390 / 320px | 页面不整体横向溢出，长代码在自身容器滚动，侧栏/辅助面板可关闭 |
| 缺权限、直连无捕获、断线、保存失败 | 既有降级信息保留，无虚构模型名、审批状态、用量或保存成功 |
| 公网绑定、电脑切换、局域网配对 | 本机/远程/配对入口符合既有权限；目标电脑和 Run 明确，取消与旧批准不复活，断线不补发输入，授权失效清空内容 |

实现验证复用现有 App、HistoryPanel、LibraryReader、ModelMessage、reading、routes 和 terminalClient 测试，并按切片补必要回归。构建使用标准入口，浏览器使用系统 Chrome；真实 CLI、网络故障和手机设备检查另列条件与结果。
